# 文件来源与公开范围

此仓库由本地开发目录按明确文件清单整理，原工程保留。公开内容包括固件、公开使用说明、一个便携硬件快照及有日期的制造附件。

`source-manifest.json` 记录复制来源（相对原项目根目录）与源文件 SHA-256。无线配置的公开版本由演示密钥替代；其余固件业务源码和原 OpenOCD 配置按源文件复制并统一为 LF 换行。新增的板级默认配置提取自原 sdkconfig 的 Flash 参数。历史日志的 MAC 已按角色替换，并清理行尾空格。

不公开本地 `.vscode`、账户数据、原生数据库、工具链、虚拟环境、构建目录、聊天/代理记录、调试日志、临时文件和重复备份。不收入原官方 Hello World 的过时测试与 README。

仓库名建议 `esp32c3-pc-prototype`，简介建议：

> 自制 ESP32-C3 USB / ESP-NOW 通信原型，包含原生 ESP-IDF 三角色固件、硬件快照与构建烧录文档。

发布前由项目所有者确认仓库名称、公开范围及许可证，并在完成本地准备后再提交与推送。
